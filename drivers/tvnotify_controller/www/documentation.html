TvNotify Controller

Control4 driver that sends to several TvNotify room drivers at once

The Controller works with the TvNotify room drivers (one per TV endpoint) and treats them as one system. It can:

  • Send any room driver command to all TV endpoints, to one, or to a named subgroup (for example "Upstairs") - up to 12 members and 6 subgroups.
  • Show each member's Online / Offline state, with variables and events for programming.
  • Hold up to 20 profiles - notifications or settings prepared once and sent with a single, quick-to-open Send Profile command.
  • Act as an Experience Button that opens the TV Notifications page in the Control4 app and on touch screens: send messages, use profiles as quick messages, save new profiles and clear badges.

Setup

Before you start

  • Add and set up one TvNotify room driver per TV endpoint (see the room driver's documentation), and check each one with its Send Test Notification action.
  • Requirement: Control4 OS 3.3.0 or later.

Step 1 - Add the Controller

In Composer, add TvNotify Controller to the project (any room).

Step 2 - Connect the room drivers

In the Connections tab, connect each TV Member N binding (Control Outputs / Other) to the TvNotify Controller binding of a room driver. Then set Number of TV Members to the number you connected: the properties page shows one Member N line per member, with its name and status. The Connections tab always lists all 12 TV Member bindings - only connect as many as you set.

Step 3 - Subgroups (optional)

Set Number of Subgroups, then give each subgroup a name and its member numbers (see Subgroups below).

Step 4 - Profiles (optional)

Set Number of Profiles and fill in the Profile Editor for each profile (see Profiles below).

Step 5 - The TV Notifications button

Show the button in a room: System Design → (room) → Room Properties → Navigator tab → Device Visibility and Display Order, and tick TvNotify Controller in the menu you want (for example Comfort, or any Experience menu). Repeat for each room, then refresh the Navigators.

Step 6 - Next steps

  • Program with Send Profile, or with the full commands and their Targets (see Programming commands).
  • Camera popups use each member room driver's own Camera Snapshots properties, so set those on every room driver.

Note: badges and the clock
Out of the box, TvOverlay shows badges at the same visibility as its clock. So if Set Overlay sets Clock Visibility to 0, badges disappear too. To hide the clock but keep badges, use Set Notification Settings with:
  • Display Fixed Notifications = On
  • Fixed Notification Visibility = 95 (or any value above 0)
Badges then keep their own visibility, whatever the clock is set to.

Profiles

A profile is a notification (or setting) prepared once in the Profile Editor and sent to many TV endpoints with one simple command.

  • Sending: in Programming choose Send Profile (the first Device Specific Command) and enter the profile number.
  • Badges: a Fixed profile's corner badge is removed with Clear Profile Badge (same number). This only clears the badge from the TV endpoints - the profile itself is kept.
  • Cameras: Camera profiles use each member room driver's own Camera Snapshots properties (Default Vendor, Encode the Image to Base64?, Address Method and Login Method). Use Default in Camera Vendor means each member room driver's own Default Vendor. For cameras not in the project fill in Snapshot URL / Stream URL (a login can be written into it: http://USER:PASS@host/snapshot.jpg).
  • Storage: profiles are stored in the controller and survive reboots and driver updates. A profile number above Number of Profiles, or one not yet set up, sends nothing and writes a line to the log.
  • Older profiles: profiles made with earlier versions (hex colours) load as Custom with the colour already picked.

TV Notifications page (Experience Button)

Selecting the Controller's button in a room Navigator opens the TV Notifications page: a simple front end for sending instant messages to the TV endpoints, or saving them as profiles to use again. It is stored in this driver and served by the controller itself, so no extra network port is opened.

Simple mode

For everyone: choose All TVs or a subgroup, then tap a quick message (every profile that is set up appears as a tile - its targets decide which TV endpoints get it), or type a message and press Send (a plain notification with the default style).

Advanced mode

Tick individual TV endpoints (with their online status; offline ones cannot be ticked) or pick a group, then send a Notification, Alert, Camera popup (camera and Snapshot / Stream / both) or a Badge that stays on screen (optionally removed after a number of seconds). It also shows On screen now - the badges sent from the page or by Fixed profiles, each with a Clear button - and the 20 most recent sends. Results show how many TV endpoints a message was sent to; whether each one displayed it is not reported back.

Save as profile (under Send) stores the message as a Controller profile: enter a Profile name (filled in from the Title or Message) and choose Save to - the next empty slot, or an existing profile to replace (tap Save twice to confirm a replacement). Type, ticked TV endpoints, alert type, title, message, camera and Show, corner, duration and the badge's Remove after are saved; everything else stays at its default and can be refined in the Profile Editor. A profile targets all TVs, one TV or one subgroup, so the ticked TV endpoints must be one of those (offline ones may be left out); any other mix is refused. If the next empty slot is above Number of Profiles, that number is raised automatically. The new profile appears in Quick messages and in the Profile summaries straight away.

The page remembers which mode you used last. It is updated by the Controller whenever something it shows changes (a TV endpoint going online or offline, a badge added, cleared or expired, a send, a profile change), and asks for the latest state when it is opened or comes back on screen. History and the badge list are kept in memory, so a controller restart clears them.

Programming commands

In Programming → Device Actions → TvNotify Controller. Send Profile and Clear Profile Badge take a single profile number. Every other command's line in the Script screen is a short summary made from its Description field and its target, for example Send Notification on TvNotify Controller to Subgroup 1: "Doorbell" (Title: Front door).

Note:
Description is only a label for the Script screen - it is not sent to the TV endpoints. Without it, Composer would list every parameter of the command in the Script line, most of them empty. Send Profile and Clear Profile Badge deliberately have no Description text box, to keep them quick to open.

Targets: All Members, Member 1 - 12, or Subgroup 1 - 6. Composer's list always shows the numbers, so check the Subgroup N Name properties to see which is which. A target with no connected member (or an empty / unknown subgroup) sends nothing and writes a line to the log.

Tokens: Title, Message, Source and Fixed Message accept {TIME} {TIME12} {DATE} {DAY} {DATETIME} {DEVICE}, replaced by each room driver when the command runs.
Cameras: for Send Camera Notification each member room driver does the camera lookup and image fetch itself, using its own Camera Snapshots properties; Output, Camera Vendor, Snapshot URL and Stream URL are passed to every member.
Room driver only: Set Settings, Set MQTT, Send Raw JSON and Dump Camera Info are on each room driver.
